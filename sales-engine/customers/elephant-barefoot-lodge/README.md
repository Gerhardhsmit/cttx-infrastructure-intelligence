## 🔧 Information Required to Complete

### From Link Planner Output:
Please provide the Link Planner analysis files (usually .lp or PDF report). Extract:

1. **RF Coverage Analysis**
   - Predicted signal strength at installation site
   - Fade Margin calculation
   - Expected throughput / capacity planning
   - Recommended antenna specifications (gain, type)
   - Frequency band confirmation

2. **Propagation Model**
   - Terrain elevation profile
   - Fresnel zone clearance
   - Loss budget analysis

3. **System Specifications**
   - Distance to Varrucom transmitter
   - Line-of-sight path analysis
   - Recommended equipment (modem, antenna, power)

### From KMZ File:
The Google Earth file should contain:

1. **Site Coordinates**
   - Lodge location (latitude/longitude)
   - Installation point (rooftop/tower)
   - Varrucom transmitter location(s)

2. **Terrain Analysis**
   - 3D terrain visualization
   - Obstacles/trees/buildings in signal path
   - Distance measurements

3. **Coverage Zones**
   - Expected WiFi coverage areas
   - Primary link path
   - Alternative backup path(s)

**How to extract:**
- Open KMZ in Google Earth Pro
- Check "Place names" for coordinates
- Use "Measure" tool for distances
- Export terrain view as image if available

### From Existing Client Information:
Please provide any documents showing:

1. **Current Network Setup**
   - Existing connectivity solution (satellite, LTE, fiber?)
   - Current ISP/provider
   - Performance issues being experienced
   - Network topology

2. **Capacity Requirements**
   - Number of concurrent guest WiFi users expected
   - CCTV camera count and bandwidth requirements
   - Peak bandwidth needs
   - Guest WiFi vs. operations priority

3. **Site Access & Power**
   - Available roof/tower space
   - Electrical power available (voltage, capacity)
   - Lightning protection / grounding
   - Access restrictions or security considerations

4. **Contact Information**
   - Correct business registration name
   - Decision-maker name and contact
   - Technical contact for implementation
   - Preferred contact method

## 💼 Configuration Selection Guide

### When to recommend Configuration A (Small Lodge):
- 20-30 concurrent users expected
- Light guest WiFi usage
- Basic operations (POS, admin only)
- Budget-conscious
- Estimated TCO: **R 149,500** over 24 months

### When to recommend Configuration B (Medium Lodge):
- 50-70 concurrent users
- Moderate guest WiFi + operations
- Light CCTV backhaul (5-10 cameras)
- Balanced reliability and cost
- Estimated TCO: **R 224,825** over 24 months

### When to recommend Configuration C (Large Resort):
- 100+ concurrent users
- Heavy guest WiFi usage
- Full CCTV system (20+ cameras)
- Business-critical connectivity
- Multiple backup paths needed
- Estimated TCO: **R 480,355** over 24 months
