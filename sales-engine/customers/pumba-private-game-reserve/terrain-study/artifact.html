01

Where things stand today

Pumba runs two lodges, a day-safari arrivals point and a Big 5 security operation on one reserve. The connectivity that is described is lodge Wi-Fi. We propose one backbone that belongs to the reserve and reaches the field.

02

Carrier in, private network out

Carrier connectivity comes into the reserve once. Everything past that point runs on infrastructure the reserve owns.

Layer 1 · Carrier

Uplink from Makhanda high ground

An uncontended business-grade Vodacom service, delivered by CTTX over a 14.2 km link to High Site South. LTE failover keeps the reserve connected if the carrier path drops.

Layer 2 · Backbone

Ridge high-sites

High Site South (509 m) and High Site North (692 m) sit 6.1 km apart with a clear link between them. Each site runs on solar and lithium storage with remote monitoring, so the network stays up through load-shedding.

Layer 3 · Distribution

Every lodge and ops site

Sector radios reach the lodges, HQ, the anti-poaching base, ecology, the workshop and the gates. A LoRaWAN gateway is ready for fence, water-point, pump and fuel sensors.

Built for what comes next

Once the backbone covers the reserve, a new camera, sensor or lodge is an endpoint on a network that is already there. It is not a new infrastructure project or a new provider contract.
