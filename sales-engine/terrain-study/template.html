02

Carrier in, private network out

Carrier connectivity comes into the reserve once. Everything past that point runs on infrastructure the reserve owns.

Layer 1 · Carrier

Uplink from {{UPLABEL}}

An uncontended business-grade Vodacom service, delivered by CTTX over a {{UPKM}} km link to {{UPTO}}. LTE failover keeps the reserve connected if the carrier path drops.

Layer 2 · Backbone

Ridge high-sites

{{BACKBONE_TEXT}} Each site runs on solar and lithium storage with remote monitoring, so the network stays up through load-shedding.

Layer 3 · Distribution

Every lodge and ops site

Sector radios reach the lodges, HQ, the anti-poaching base, ecology, the workshop and the gates. A LoRaWAN gateway is ready for fence, water-point, pump and fuel sensors.

Built for what comes next

Once the backbone covers the reserve, a new camera, sensor or lodge is an endpoint on a network that is already there. It is not a new infrastructure project or a new provider contract.
